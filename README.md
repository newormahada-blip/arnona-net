# ארנו-נט

מערכת לעיריות לאיתור עסקים שפועלים מנכסים שמסווגים כמגורים בארנונה. העבודה עוברת שלושה שלבים:
1. **איתור:** סוכן AI מוצא עסקים ומצליב אותם מול נכסי הארנונה.
2. **סקר:** עובדי העירייה מנהלים את הממצאים ושולחים אותם לסוקרי שטח.
3. **מעקב:** מנהל האגף רואה תמונת מצב ופילוח לפי שכונות.

- **אתר:** Next.js (סטטי), שמתפרסם ב-GitHub Pages.
- **מסד נתונים והתחברות:** Supabase.
- **מפה:** OpenStreetMap.

## התקנה לעירייה חדשה

כל עירייה מקבלת התקנה נפרדת. ראו [`installer/README.md`](installer/README.md).
כל מה שקושר את האתר לעיר מסוימת נמצא בקובץ אחד, `city.config.json`, והוא נוצר בהתקנה.

## פיתוח

```bash
npm ci
npm run dev
```
